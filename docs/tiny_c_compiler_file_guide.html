TinyC compiler file guide

Source → lexer → parser → symbols → semantics → three-address code → output.

Files

tokens.py defines locations. lexer.py scans. parser.py creates a tree. semantic.py checks it. codegen.py emits and executes TAC.

Grammar

statement = declaration | assignment | print | block | if | while | for

Run python3 -m tinyc.main --serve.
